## 2. 五分钟速查卡

### 角色与门禁（G1–G5）

| 门禁 | 判什么 | 负责人 | 执行人能否自放行 |
|---|---|---|---|
| G1 需求评审 | 目标清晰、验收可测、范围无歧义 | PM + ARCH + QA | — |
| G2 设计评审 | 模块边界、回归范围、风险缓解 | ARCH | — |
| G3 提测门禁 | 自测通过 + `verify.py` 全绿 + 无 TODO 遗留 | DEV | **否** |
| G4 质量门禁 | 无 P0/P1 遗留、回归无新增失败、四页截图核对 | QA | **否** |
| G5 发布门禁 | 冷启动冒烟通过、回滚方案在位、产物不含凭证 | 交付总监 + QA | **否** |

> 铁律：**门禁执行人不得是执行人本人**。确需放行由交付总监书面例外并记入 CHANGELOG。

### 硬约定（已拍板，不再讨论）

| 项 | 约定 |
|---|---|
| 版本号 | `MAJOR.MINOR.PATCH`，单一真源 = `bilidownloader/__init__.py::__version__`，**任何文件禁止写死版本号字面量** |
| 分支 | `main`（可发布）/ `develop`（集成）/ `feature/*` / `hotfix/*`；hotfix 从 main 拉，修完双合 |
| 提交信息 | Conventional Commits：`feat` `fix` `docs` `refactor` `perf` `test` `chore`，可带 scope |
| 分层依赖 | 页面 → 队列/引擎 → 外部二进制，单向；**views 层禁止 `subprocess`、禁止直调 yt-dlp、禁止跨页面互相 import** |
| 主题颜色 | 一律走 `theme.py` 令牌，禁止硬编码颜色；自定义 `QFrame` 必须用 `#ObjectName` 限定选择器 |
| 退出安全 | `closeEvent` 必须调 `manager.shutdown()`（运行中销毁 QThread 会直接崩进程，且无 traceback） |
| 打包 | `bin/` 不入库；`.spec` 必须带 `bilidownloader/assets`；发布物不得含 `data/cookies.txt` |

### 每次提交前必跑

```bash
PY="C:/Users/<你的用户名>/.workbuddy/binaries/python/envs/default/Scripts/python.exe"
cd "<项目目录>"
$PY -u verify.py        # 54 项（以脚本实际打印的 [PASS] 行数为准），必须全绿、退出码 0
$PY screenshot.py       # 改了界面就必须重跑，产出 data/screenshots/ 共 12 张
```

改了哪些文件就要重跑哪些测试，映射表见 `03` §2.3。

## 3. 当前的真实 Backlog（PM 定级，可直接排期）

| 事项 | 分级 | 说明 |
|---|---|---|
| yt-dlp / ffmpeg 版本升级与校验机制 | **P0** | 接口一变全线失效；需版本追溯清单 + 一键更新（规范已定，见 `01` §7.4/§7.5） |
| `data/cookies.txt` 凭证保护 | **P0** | 防误打包、防日志打印、防截图泄漏、一键清除（见 `01` §8.3） |
| 侧边栏「批量下载」 | P1 | 必须内置防风控节流 |
| 侧边栏「收藏夹」 | P1 | 依赖登录态稳定 |
| 侧边栏占位项统一"即将上线"提示 | P1 | 当前禁用但无解释，属体验缺陷 |
| 风控自适应限速 / 重试退避 | P1 | 影响成功率与账号安全 |
| 「字幕与弹幕」独立页 | P2 | 详情页已支持，独立页属增强 |
| 打包体积优化（约 261MB） | P2 | 不影响可用性 |
| **账号密码登录** | **不做** | 已裁决：需 RSA + 验证码 + wbi 签名，成本高且易触发风控；保留「扫码登录 + Cookie 导入」并优化引导 |
